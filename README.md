# 瑷珲非遗 · 幼儿美育 AI 备课助手

面向 **3–6 岁幼儿园** 的非遗美育 AI 助教：把「瑷珲花灯、掐丝珐琅、纸浆画、赫哲族鱼皮画、满族民间剪纸、麦秆剪贴、达斡尔族哈尼卡」七项非遗，做成可离线运行的网页助手 + 结构化知识库 + 可复用的提示词工程方案。

打开 `web/index.html` 即可用（单文件，无需服务器、无需构建）。不填 API Key 也能查本地资料、拼教案；填了 DeepSeek Key 则由大模型生成。

## 为什么值得看

大多数「AI + 教育」项目的问题不是模型不行，而是**模型不知道你们本地的非遗长什么样、材料够不够、孩子这个年龄做不做得成**。这个项目把三件事做进了本地：

1. **结构化知识库**：7 个非遗 × 11 个字段（来历 / 工艺 / 纹样寓意 / 园内可用材料 / 安全红线 / 分龄要点 / 常见误区 / 教师话术 / 一句话给家长 / 延伸提问 / 常见问答）
2. **63 套成品教案**：7 主题 × 3 班（小/中/大）× 3 套方案，每套 12 个语义字段（活动/故事/童谣/环创/手工/室内外游戏/提问/评价/家长任务/睡前共读…）
3. **材料—工艺适配规则**：66 种生活常见材料，按「绿=可用 / 黄=需先处理 / 红=用不上」判定，红黄都给出**为什么**和**还能用在哪**。避免出现「只给孩子贝壳和纸箱，却让他做剪纸」这类不可行的方案。

## 快速开始

### 方式一：直接打开（推荐）

```bash
git clone https://github.com/<your-name>/aihui-feiyi-ai-assistant.git
cd aihui-feiyi-ai-assistant
# 双击 web/index.html，或
python -m http.server 8000   # 然后访问 http://localhost:8000/web/
```

不联网也能用：查资料、按主题/班次拼出教案、导出 Word。

### 方式二：接大模型

页面右下角 → 🔑 填写 **DeepSeek API Key**（只存在浏览器 localStorage，不上传任何服务器）。填完后「生成教案 / 环创方案 / 家长卡」走模型；失败自动回落本地库。

## 目录结构

```
web/index.html            单文件应用（HTML + CSS + JS + 知识库全在一个文件里）
data/
  themes.json             7 个主题的元信息、文化背景、年龄段标签
  kb-card.json            知识卡：7 主题 × 11 字段
  plans.json              63 套方案，每套 12 字段
  fulltext.json           拼接后的课程包全文（用于全文检索）
  materials-rules.js      材料—工艺适配规则（66 材料 / 7 主题 / 判定函数）
prompts/
  soul.md                 人设（system 的第一段）
  train.md                训练补充：年龄特点、速查表、四类产出模板、工具规矩、自检五问、红线
docs/
  architecture.md         架构与调用链
  knowledge-base.md       知识卡字段说明与维护方式
  materials-fit.md        材料适配规则是怎么定的
  usage.md                教师使用手册（怎么问、怎么改、怎么导出）
scripts/
  check_data.py           数据完整性自检（字段数、方案数、空值、术语一致性）
```

## 它怎么回答（调用链）

```
用户提问
  └─ system = soul.md + train.md + 【本次聚焦主题】 + 知识卡摘要 + 教案原文摘要
       └─ 模型判断要不要调工具
            ├─ read_resource(theme, field)   取教案原文 / 知识卡（history/safety/faq/toParent/extend…）
            ├─ search_kb(q) / read_full(theme) 本地全文检索
            ├─ gen_lesson / gen_decor / gen_pair  写成品
            └─ audit_lesson(text)            教案六环节体检
```

关键设计：**知识卡既进 system，也能按需单取**。前者保证回答不跑偏，后者保证长对话不把上下文撑爆。

## 术语与表述约定

项目里所有面向老师与家长的文字，遵守以下约定（`scripts/check_data.py` 会检查）：

- 写「瑷珲」，不写「爱辉 / 瑷晖」
- 写「满族民间剪纸」，不写「东北剪纸」
- 写「赫哲族鱼皮画」，首次出现带族名
- 写「麦秆剪贴」，不写「麦杆」
- 写「达斡尔族哈尼卡」，不写「哈斡尔 / 达翰尔」；**不称「东方芭比娃娃」**
- 不编造年代、传承人姓名、获奖与政策条文；本库没有的就说「这个我得查一查」

## 安全底线

项目涉及 3–6 岁幼儿，内容层面内置这些硬约束（写在 `prompts/train.md`）：

- 不点火、不接电、不给幼儿真实灯具/蜡烛
- 剪刀：小班只撕不剪；中班圆头安全剪 + 教师预剪；大班安全剪且全程看护
- 麦秆须打磨去刺消毒；鱼皮画一律用仿鱼皮材料，不接触真实鱼皮
- 豆子/大米/纽扣等小件，3 岁以下班级慎用
- 塑料瓶、锡纸、泡沫板等锋利或易碎材料，标注「仅教师操作」
- 不索取儿童姓名、照片、联系方式

## 数据怎么来的

- 非遗史实与工艺：公开资料整理，并在 `docs/knowledge-base.md` 中标注了哪些属于**可核实的公开信息**、哪些是**教学化改写**
- 教案与环创：按幼儿园一线需求编写，非出版物内容
- 图片：演示图部分由 AI 生成，仓库内不包含生成原图（避免版权与体积问题）

**本项目的知识卡与教案文本用于教学参考，不作为正式出版物、学历教育材料或培训招生宣传使用。**

## 如何扩展

- **加一个非遗主题**：在 `data/themes.json` 加 meta + heritage → 在 `data/kb-card.json` 加 11 个字段 → 在 `data/plans.json` 加 3 班 × N 套 → 跑 `python scripts/check_data.py`
- **改材料规则**：`data/materials-rules.js` 里 `CATS`（分组）/ `NEED`（每主题可用）/ `PREP`（需先处理）/ `ELSEWHERE`（还能用在哪）
- **调人设**：只改 `prompts/soul.md`，不要散落在代码里
